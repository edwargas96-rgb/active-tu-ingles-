# Activa tu Inglés — Mapa Mental

Landing page (mapa mental) para vender un método de inglés, en español,
dirigido a Latinoamérica (Argentina, Colombia, México, Venezuela, Perú,
Chile, etc.).

Sitio estático simple: `index.html` + `styles.css` + `script.js`, sin
build ni dependencias — se puede publicar directamente en Vercel, Netlify,
GitHub Pages o cualquier hosting estático.

## Estructura

- `index.html` — contenido y secciones de la página.
- `styles.css` — estilos (tema claro, tipografía, animaciones de scroll).
- `script.js` — genera el diagrama del mapa mental, rota las banderas del
  hero y activa las animaciones de aparición al hacer scroll.

## Pendiente

- Las secciones de ejemplos y los avatares de testimonios usan
  placeholders vacíos ("Imagen próximamente" / iniciales) — reemplazar por
  imágenes reales cuando estén listas.
- El botón de compra apunta a `#comprar` — conectar con el checkout real
  (link de pago, WhatsApp, etc.) cuando esté definido.
